# UI 方向说明（玩法优先 · 竞品 HUD）

## 1. 玩法（必须先搞对）

| 错误画法 | 正确画法 |
|----------|----------|
| 心形/满盘 **等大小单格** | **多块异形果冻**：1～5 格连成一块，**一块一箭头** |
| 每格一个箭头 | 箭头只在 `arrowCell`，整块点击飞出 |
| 棋盘铺满格子 | 矩形网格上只占 **部分格**，中间可 **空洞** |
| 对局露底图 | 对局 **只有块+淡网格**，图在通关/首页/结算 |

权威几何：`玩法画法样板.svg`、`UI原型/design_v5/04_game_default.svg`（6 块 L/凹/长条，**剩余 6 块**）。

参考图（Tap Block Out）是 **同款品类** 的 UI 壳（暖色、厚块、顶栏进度、圆道具），但其 **心形单格阵 ≠ 我们的关卡数据结构**。  
**只借鉴 HUD/配色/道具布局，棋盘必须跟 `pieces[]` + `shapeId` 异形块。**

## 2. 竞品里「更好看」采什么

| 竞品 | 采纳 |
|------|------|
| **Arrow Out Puzzle** | 淡虚线网格、留白、箭头清晰（→ 04 已定稿） |
| **Tap Block Out** | 暖米底、圆角厚实体感（材质可做微 3D，但轮廓仍是 **连续 path**） |
| **箭头消除** | 米纸暖底、克制装饰 |
| **本项目 04/06** | **棋盘与果冻语法已定稿**，竞品对标文档推荐「极简骨架 + 沉浸换皮」 |

**不采纳**：把心形单格阵当 BlockOut 棋盘；design_v5 以外我写的 CSS 小方块阵。

在 **04 的 path 不改** 前提下，仅改 HUD 层（绿条+礼盒、Combo、金币胶囊）——需产品确认是否进首发；代码现状见 `BuildBoardScreen`（无礼盒进度条）。
