## 首发冻结规则摘要（以 09 §0 为唯一来源）

1. 关卡编号全局递增：第一章 1–12、第二章 13–24；显示"第一章 · 第 4 关"。
2. 每章 12 关 = 12 拼片；**拼片模型 = 一章一张完整插画拆 12 个揭晓区域，一关解锁一区域**；重复通关不重复解锁（3/12、还差 9 片）；失败占位图全章共用 1 张。
3. **坐标方案**：完整图/预览图/剪影图/12 区域遮罩共用 1080×1080 画布（region_01–12 ↔ 第 1–12 关，每区 270×360），**region 固定在源画布、不随容器重新划分**；缩略类容器 cover 裁切（禁止拉伸），**大图查看页与章末完整图揭晓用 contain/完整显示**。
4. 复活：**单次挑战唯一一次复活**；全局 1–10 关每关首次失败免费（带徽标），第 11 关起 = 激励广告或 300 金币；**复活后再次失败只能重开/退出**；生命 +1 心 / 倒计时 +30 秒；重开或放弃后资格重置。
5. 首发默认生命模式（3 心）；倒计时默认关闭仅远程开关；HUD 互斥；同块重复错误不重复扣心。
6. 前章 12/12 解锁下一章；未发布章节显示"新章节准备中"，不开放空关卡。
7. 初始 300 金币；Hint 3 / Hammer 1 / Magic 0；解锁关卡 7 / 11 / 16；购买与金币复活 300 金币。
8. **购买方案**：首发 = **本地金币事务，无服务端依赖**；按钮单飞锁防重复扣币、成功写入本地存档、失败不扣币不发奖；将来接服务端/IAP 走 `IPurchaseProvider`，UI 交互规格不变。
9. 魔法棒 = 一次自动移除**最多 3 个**可飞块 + 星星特效（代码 `MagicTargetCount=3`，逐次重新判断），不是重排；锤子 = 选择态工具（进入不扣库存，可消任意在场块）。
10. 正式资源 = 糖果主题 + 可商用授权；示意剪影/emoji/占位/FakeAdProvider 仅限原型。
