## 2. 字体层级（Source Han Sans CN Regular，8pt 栅格）

> **字体已交付**（2026-10-15）：`Assets/Resources/Fonts/SourceHanSansCN-Regular.otf` + `LICENSE.txt`（SIL OFL 1.1，Adobe 原文）+ `SOURCE.md`（来源 URL 与 SHA-256）。允许随应用嵌入与再分发。**不再使用 PingFang SC / Microsoft YaHei 作为交付字体**（二者禁止打进正式包）。
> 度量实测（upem 1000，CFF OpenType，usWeightClass 400）：CJK 字面为全宽（≈1.0em），ASCII 数字/字母为半宽（≈0.5–0.6em）；ascender 1160 / descender −288 / lineGap 0（hhea），typo 880 / −120（OS/2）。**中英混排行宽按 CJK 1.0em + 西文 0.55em 估算**，与本表字号栅格兼容。
> **设计稿字体栈**（2026-10-15 统一）：`'Source Han Sans CN','Noto Sans SC','Microsoft YaHei','PingFang SC',sans-serif`——思源黑体优先，与项目已交付字体一致；雅黑/PingFang 仅作回退。**此前统一用雅黑优先，在部分渲染环境会回退到衬线字体，导致小字出现衬线观感、与标题按钮字不一致**，现已修正。
> **禁用/未激活文字色**：由 `#B9A79B`（对比度约 2.2:1，手机尺寸不可读）改为 **`#8A7568`**（约 5.2:1）；图标置灰仍用 `#B9A79B`（非文字载体）。锁定条件与数量信息必须同时有文字，不靠颜色单独表达。
> **粗体**：包内仅 Regular 单一字重，粗体由 UGUI `FontStyle.Bold` 合成（描边加粗，不改变字宽）。移动端实际粗细效果与中文可读性**待 Unity 验收**；若 Bold 合成过重或过轻，替代方案为补装 `SourceHanSansCN-Bold.otf`（同 OFL 1.1，同一上游仓库可得），不影响字号栅格与行宽。

- 描边：卡片 2px `#F0DCCB`；按钮 1.5px；棋盘 3px `#E8CDBB`。
- 投影（果冻块）：`dy=7, blur=6, 22%, #674138`；卡片投影同 Token 可降为 `dy=4, blur=4, 18%`。
- 果冻块结构：竖向渐变体色 + **3px 白色外轮廓（opacity .92，唯一块边界）** + **1px 内格线（白 .22，两端各内缩 6px、圆头）** + 短投影。
  **内格线仅作块内纹理，不得让一个多格拼块看起来像多个独立块**：外轮廓是唯一的块边界，内格线降低不透明度并内缩端点，读作块内细节而非块间分隔（2026-10-15 修订）。箭头 = 白色填充 `#FFFEFA` + 1.4px `#5A4038` 描边（paint-order: stroke fill）。
- **道具锁定态**：图标 `#C9B8AC` 置灰 + 右上锁徽章（`#8A6E62` 圆底 r10.5 + 白色 9px 锁形）+ 名称下 9px 条件文案（如"第 11 关解锁"）。
- 触控目标 ≥ 44×44。

### 6.1 收藏页滚动内容区 / 固定导航 / 触控热区

- **滚动内容区**：章节列表卡（312×132）+ 重复挑战关卡网格放在 **ScrollRect 内容区**内，可垂直滚动；**底部导航条固定不参与滚动**，始终吸在安全区上方。

### 8.3 状态规则

- **棋盘四态**：默认（全中性）/ 可飞提示 / 点击受阻 / 飞出中 —— 见 `05_game_states.svg` A 区。**红色只用于受阻点击后的短暂反馈（≤280ms + Toast），默认状态禁止预标答案。**
- **锤子选择态（05-F）**：点击锤子进入选择态（不扣库存），全部在场块（含受阻块）显示可可虚线选中环 + 锤子光标；点块 → 消除并扣 1 库存；再点锤子或棋盘空白处 → 取消选择态（不扣库存）。**与可飞提示的区别：提示 = 薄荷辉光只标"可飞块"；锤子 = 任意在场块可消。**
- **魔法棒（05-G）**：一次施法自动移除最多 3 个当前可飞块（代码 `MagicTargetCount=3`，可远程配置）；不足 3 个全部移除；场上无可飞块时不消耗；被选块逐个飞出 360ms + 星星特效 600ms。
- **HUD 双模式互斥**：生命模式（3 心，错误扣 1，同块重复不重复扣）与倒计时模式（时间耗尽即失败，错误只震动 + Toast）二选一，由远程 `ArtOutUseTimeFailMode` 控制；**首发默认生命模式**；心与计时器不得同屏。
- **道具三态**：正常 / 数量为 0（置灰 + Toast，不跳转）/ 未解锁（置灰 + 锁 + 等级条件）。初始数量 3/1/0，解锁关卡 7/11/16（全局号）；第 4 关三道具均未解锁为设计预期。
- **暂停冻结**：暂停层弹出即冻结（计时/动画/输入）；退出本关与重开均清本局进度；重开重置复活资格；**重开不返还已消耗道具与已扣金币**。
- **失败与复活**：弹窗显示失败原因（生命耗尽/时间用尽）；**单次挑战唯一一次复活**，按资格取其一：免费（全局 1–10 关每关首次失败，带"免费"徽标）> 激励广告（就绪可点；加载中转圈；失败 Toast 并回退 300 金币）> 300 金币（足够可点 / 不足置灰 + Toast，**仅提示不跳商店**）；第 11 关起无免费资格；**复活后再次失败只能重开 / 退出**；免费徽标只在免费态出现。
- **商店（15）**：三商品单价 300 金币；未解锁商品显示等级条件并禁买；**首发购买 = 本地金币事务**（`BlockOutPlayerProfile.SpendCoins` + `AddToolCount`，即时写入本地存档），UI 层 `storePurchasing` 单飞锁实现**防重复扣币**（点击后按钮禁用 + 「请稍候」，事务完成才恢复）；失败（余额不足/未解锁/异常）**不扣币、不发奖**并回退按钮；金币获取 = 通关奖励 + 重复挑战（数值待经济表 ◆）；**首发不提供金币内购，失败层无"去商店"引导**。若将来接服务端/IAP，新增 `IPurchaseProvider` 接口，不改 UI 交互规格。
- **收藏（14）**：一张章节卡 = 一个章节；列表卡 312×132（左右 24 · 卡间距 12）；锁定 = 整章剪影 + 入口禁用；部分解锁 = 已揭晓区域可查看 + "还差 N 片"，大图只叠已揭晓区域；12/12 = 完整大图 + CTA 切"进入下一章"；图片失败 = 占位 + 重试（不阻塞列表浏览）；重复挑战关卡网格：已通关可进、未通关锁定。
- **设置（16）**：首发仅 音乐/音效/震动 开关 + 关于；通知/恢复购买未纳入首发**不展示无效入口**；开关本地存档立即生效；从暂停层进入返回时对局保持暂停。
- **章末结算（17）**：第 12 关通关触发；12/12 + 完整章节图揭晓（12 区域依次点亮 400ms/60ms）；下一章已发布 → "进入下一章 · 第 13 关"；未发布 → "新章节准备中"禁用态（不可进入空关卡）；保留 查看收藏/重玩/返回首页。
- **揭晓一致性**：首页预览卡 / 关卡结算 / 收藏页三处揭晓结果一致（同一 1080×1080 画布 + 12 区域遮罩，见 11 §1.1 与 `ch01_region_mask.svg`）。**region 固定在源画布**：无论容器如何变换（首页预览卡 / 收藏缩略 / 结算揭晓框 / 章末图 / 大图），region 像素区域以 1080×1080 源画布为唯一基准，**不得按容器重新划分**。缩略类容器用 cover；**收藏大图查看页与章末完整图揭晓必须 contain/完整显示，不得裁掉作品边缘**（详见 11 §1.2）。
- **首页状态**：新用户（开始第 1 关、0/12、整图剪影、初始 300 金币）/ 章节完成（12/12、CTA"进入下一章"）/ 第二章未发布（"新章节准备中"禁用态，入口不可点）/ 图片加载失败（占位 + 重试，**不阻塞开始游戏**，对局不显示底图）/ 小屏安全区（360×640 规则见 §6 与 `12_screen_adapt_360.svg`）。
