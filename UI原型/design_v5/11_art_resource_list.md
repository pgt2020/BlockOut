### 1.1 坐标方案与区域对应表（方案 A：统一画布 + cover 裁切）

**画布坐标系**：1080×1080，左上原点；12 区域 = **4 列 × 3 行**，每区 **270×360**，合起来**完整覆盖画面，无缺口、无重叠**。

| region | 网格位置 (col,row) | 像素区域 (x,y,w,h) | 对应关卡 |

| region_01 | (0,0) | 0, 0, 270, 360 | 全局第 1 关 |
| region_02 | (1,0) | 270, 0, 270, 360 | 全局第 2 关 |
| region_03 | (2,0) | 540, 0, 270, 360 | 全局第 3 关 |
| region_04 | (3,0) | 810, 0, 270, 360 | 全局第 4 关 |
| region_05 | (0,1) | 0, 360, 270, 360 | 全局第 5 关 |
| region_06 | (1,1) | 270, 360, 270, 360 | 全局第 6 关 |
| region_07 | (2,1) | 540, 360, 270, 360 | 全局第 7 关 |
| region_08 | (3,1) | 810, 360, 270, 360 | 全局第 8 关 |
| region_09 | (0,2) | 0, 720, 270, 360 | 全局第 9 关 |
| region_10 | (1,2) | 270, 720, 270, 360 | 全局第 10 关 |
| region_11 | (2,2) | 540, 720, 270, 360 | 全局第 11 关 |
| region_12 | (3,2) | 810, 720, 270, 360 | 全局第 12 关 |

**裁切映射（cover，禁止拉伸）**：统一公式 **`scale = max(容器宽/源图宽, 容器高/源图高)`**；先按 scale 等比缩放，再**居中裁掉超出容器的部分**（禁止非等比拉伸）。

- 源图为正方形（1080×1080）时：**宽容器裁上下，窄高容器裁左右**。例：312×210 预览卡宽高比 ≈1.49（宽容器）→ 裁上下，可见源图中央 1080×720 横带；120×124 缩略（窄高）→ 裁左右微裁；64×64（正方）→ 不裁。
- **底图（full/preview）、剪影 silhouette、12 区域遮罩必须使用同一变换**（同一 scale + 同一裁切原点），否则遮罩与底图错位、揭晓区域偏移。

| 显示容器 | 尺寸 | 适配方式 | 可见源区域 |
|---|---|---|---|
| 首页预览卡 | 312×210（390 档 342×300） | cover 居中 | 宽容器 → **裁上下**：312×210 可见中央 1080×720 横带；342×300 微裁上下 |
| 收藏章节卡缩略 | 64×64 / 52×52 | cover 居中 | 中央正方形，不裁 |
| 收藏摘要卡缩略 | 120×124 | cover 居中 | 近正方形，窄高 → 裁左右微裁 |
| 关卡结算揭晓框 | 220×96 | cover 居中 | 宽容器 → 裁上下，中央横条 |
| 章末结算揭晓卡 | 342×300，内部正方形视区 264×264 | **contain**（letterbox `#FFF7EF`） | **全图可见，不裁作品边缘**（见 §1.2） |
| 收藏大图查看页 | 全屏安全区内 | **contain**（仅 12/12 开放） | 全图 |

- 遮罩几何资产 `ch01_region_mask.svg/.png` 已由设计侧按上表产出（1080×1080，12 区域虚线边界 + region 编号 + 关号标注），可直接作为美术分层与程序合成的对齐基准。
- **一致性要求**：首页预览卡 / 关卡结算 / 收藏页三处揭晓结果必须一致（同一画布 + 同一 region 表）。
- **region 固定在源画布**：无论显示容器（首页预览卡 312×210、收藏缩略 52×52、关卡结算揭晓框 220×96、章末完整图 306×264、收藏大图全屏）如何变换，region 的像素区域（x,y,w,h）都以 1080×1080 源画布为唯一基准，**不得按容器重新划分网格**。

### 1.2 大图与完整图显示规则（contain + 防泄露）

**核心区分**：

| 场景 | 容器比例 | 适配方式 | 目的 |
|---|---|---|---|
| 首页预览卡、关卡结算揭晓框、收藏列表缩略 | 均不等于 1:1 | **cover** | 装饰性缩略，允许裁切 |
| 收藏「查看大图」页（仅 12/12 开放） | 任意 | **contain / letterbox** | **必须看到完整作品边缘**，不得 cover 裁切 |
| 章末结算「完整图揭晓」主视觉 | 342×300 卡内正方形视区 264×264 | **contain + letterbox**（两侧 `#FFF7EF`） | 章节完成仪式感，**不能裁掉作品边缘**；并保留「查看大图」入口 |

- **12/12 后大图查看**：用 `contain`（或等效完整显示），适配安全区内完整尺寸；支持双指缩放、单指拖动、双击复位、关闭/返回。缩放范围建议 `1.0–3.0`（以完整图为 1.0）。
- **部分解锁时放大**：未揭晓区域仍由 `silhouette` / 12 张 region 遮罩覆盖，**放大不得泄露完整图**；大图入口在部分解锁态置灰或隐藏。
- **章末结算完整图揭晓**：主视觉容器应保证作品完整可见；若容器比例导致两侧/上下留黑，用与 `#FFF7EF` 一致的 letterbox 背景。预览卡可用 cover，但完整图入口必须保留。

### 13.4 首发购买方案（本地事务）
