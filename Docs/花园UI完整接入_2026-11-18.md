## 用户运行验收清单

1. 打开工程，确认字体、资源和脚本正常导入，无缺图/粉材质/编译错误。
2. 首页新存档及已有存档：关号、路径、锁定与当前关一致；点击当前关与已完成关可进入；未来关不可进入；金币加号、设置、关卡、道具可用。
3. 对局：实际方块在托盘内且箭头清楚；HUD、暂停、底排方块、剩余数量和道具区不重叠；生命/计时及进度更新；三道具使用、缺少数量、未解锁状态正确。
4. 商店：长解锁文案、数量和购买价格不挤压按钮；购买成功/金币不足/未解锁/购买中显示正确，不重复扣费。
5. 关卡：章节滚动、关卡绿紫灰状态、当前关继续、历史关重玩、未来关锁定；页面底部内容不会被导航挡住。
6. 通关：真实关卡图片位于画框内，奖励与真实存档一致，下一关/返回/重玩；保存失败提示及重试流程仍可用。
7. 暂停、设置开关、重开与退出确认、失败免费/付费复活、引导、关于的标题及按钮完整，Esc/返回行为正确。
8. Game View至少检查360×640、390×844、390×932；真机另验安全区、触控、帧率、音效和震动。广告真实回调按平台流程检查。
