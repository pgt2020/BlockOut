# 功能流程审查 · 2026-11-18

## 方法与结论

阅读启动、导航、HUD、购买、复活、结算、关卡加载和存档事务代码，核对新首页路径与真实入口。属于静态逻辑审查，未启动Unity、编译、PlayMode或测试；不能据此断言实际运行全部正常。

核心单机闯关循环已经连通，具备游戏应用的基本闭环。真实广告与平台发布仍未完成验收，不等于已可正式发行。

## 流程核对

| 流程 | 代码状态与边界 |
|---|---|
| 首次进入 | 未完成引导的首关进入实际棋盘引导；新用户不是必须先看到首页。引导由BoardGuide控制，不能把静态说明弹窗当作唯一新手流程。 |
| 冷启动恢复 | 对局ID、方块数量和hash校验；支持恢复进行中、失败、待结算局。失配存档清除；启动资源异常的可恢复错误页面仍不完善。 |
| 首页/选关 | 新路径显示真实当前关和附近节点，已通关可重玩、未来关锁定；公共EnterLevel补了数据有效性和解锁检查。 |
| 暂停/设置/返回 | 返回键按弹层顺序关闭；暂停设置返回后保持暂停；退出/重开有确认。首页返回键当前不额外弹退出应用确认。 |
| 道具 | 解锁、库存、暂停、模态、飞行动画和引导状态共同控制输入；魔法待完成目标可恢复；购买走扣币+发道具事务。 |
| 商店 | 本地金币商店，不是现金支付；有购买中、未解锁、金币不足和失败反馈。 |
| 失败/复活 | 免费、广告、金币路径；对局令牌防止旧广告结果给新局发奖；复活落盘失败回滚。真实SDK调用仍未完整接通。 |
| 通关 | 真实完成图、首次/重复奖励、章节进度、下一关和重玩；保存失败阻止离开，提供重试。 |
| 全部通关 | 主按钮调整为返回首页，保留重玩和关卡页；不再停在禁用主按钮。 |
| 切后台 | 有暂停与存档逻辑，回前台由玩家继续；需要真机验证广告、系统生命周期及音频恢复。 |

## 本轮修复

1. GiveUp/RestartLevel原先清除当前对局并忽略保存结果，UI仍会返回首页或加载新局。新增TryGiveUp/TryRestartLevel，先事务提交清除操作，失败则保留档案、对局令牌、棋盘及暂停/失败弹层。原void方法保留为兼容入口。
2. 暂停/失败退出及重开回调只在成功后关闭原弹层；保存失败不会假装操作完成。
3. 结算重玩增加独立SettlementSaveFailed保护，不仅依赖按钮禁用态。
4. EnterLevel检查空目录、无效关卡数据及未解锁目标，避免无条件切到空白或不可玩的棋盘。
5. 商店进入关卡页重定位到当前主线章节，避免沿用旧浏览章节。
6. 无后续可用关卡时结算主按钮改为返回首页；下一关点击也校验章节发布/数据状态，与显示逻辑对齐。
7. 金币复活失败不再统一误报金币不足，改为未成功且未扣币的重试提示。

## 验证记录

页面引用和花园资源静态检查通过（18个Prefab、105个文本节点、26张花园贴图）。这不证明C#编译或运行正常。

增加PlayMode测试 `FailedExitOrRestart_KeepsPausedRunUntilSaveSucceeds`：内存存档注入提交失败，验证重开/退出不切局、不离开暂停棋盘，恢复写入后退出成功。遵守用户要求，仅编写，未运行。

用户应重点运行：暂停后重开、退出确认取消与确认、失败后重开/退出、结算重玩、最后一关返回首页，以及上述存档失败测试。以前旧版本的测试通过记录不视为本轮通过。

## 距离发布级完整应用仍有差距

- LevelPlayAdAdapter.Init仍明确保留SDK初始化占位；代码接口和开发模拟不是实际广告闭环。广告未就绪有金币回退，但真机广告加载/展示/奖励/取消/超时需另行接入和验证。
- 隐私/协议/平台授权、打包发布、设备性能与真机输入未在此任务完成验收。
- 加载资源失败、空目录等启动故障尚无专门的可恢复错误页；本轮只补公共进入关卡保护，没有把启动异常包装成已解决。
- 每日、任务、成就、皮肤未新增，隐藏对应假入口。它们不是单机闯关闭环的必需条件。
- 短屏整体缩放带来的小字/小触控区风险见花园UI适配专项检查报告，未因流程审查而消失。
