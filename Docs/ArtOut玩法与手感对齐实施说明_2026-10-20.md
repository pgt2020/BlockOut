## 4. 核心规则与连续点击

### 4.1 普通块

- 点按消除，禁止变成拖动滑块或自由挪动。
- 一个多格块作为完整对象沿固定箭头方向移动；检查所有占格的前进射线到矩形棋盘边界，不只检查箭头格。
- 所有射线都无其他有效块才可消除；自身占格不作为障碍。
- 生命模式初始 3 心。受阻块首次误点扣 1 心，记录 WrongMarked；同一块再次误点仍有错误演出，但不再次扣心。
- 倒计时模式受阻不扣心，仍标记和反馈。归零失败。
- 没有任何有效块且本局有合法关卡内容才算通关；空/损坏关卡不能自动发奖。

### 4.2 连续点击是本次必须恢复的体验

参考 `OnBlockClicked` 在成功后立即 `rules.Remove(target)`，再启动飞出协程。普通块飞出期间可继续点其他有效块；锤子等工具有独立锁条件。当前 BlockOut 的 `ResolvingMove` 与 BoardView 的整盘 `inputLocked` 会把普通点击串行化，必须重构。

推荐把“逻辑是否占位”“视觉是否飞行”“允许普通点击”“允许工具操作”“是否可结算”分开管理：

1. 成功点击立即将目标逻辑移除并禁用目标命中，后续判定能看到已释放的路径。
2. 每块动画独立登记，普通飞出不锁整盘；同一块不可能重复提交。
3. 最后一块逻辑移除后停止接受无效操作，但等在途飞出/必要工具演出完成再展示胜利。
4. 失败、暂停、模态弹窗、重开、手势、工具演出使用明确锁原因；一个动画完成不能误解开另一个锁。
5. 重开/退出/重建通过对局 generation/token 撤销旧回调；普通块、工具和胜负共用这一语义。
6. 保存应记录已承诺的逻辑移除；恢复全移除局必须补结算且只执行一次。不能为了防中断而退回“每块必须等动画完才能点下块”。
7. 保存失败恢复档案与对局一致状态并提示，不能显示已成功但重启丢进度。重玩是新挑战，不得用“此关曾通过”完全禁止合法重玩奖励。

道具购买数量、价格及解锁弹窗赠送规则：必须继续阅读参考 ToolController 的真实分支确定，不从当前 BlockOut 的“一次 300”注释推断。把查到的数值补入配置和交付表，不凭空创造免费无限道具。

提示：维护本局已提示集合，优先未提示的可飞块，全部遍历完再重置。无目标不扣库存；选取成功且消费成功才记入集合；切关/重开重置。不能继续使用首个块固定返回，也不要沿用 2.5 秒硬冷却。提示演出/聚焦期间是否锁输入要复核参考调用路径。

锤子：进入选择态、点有效块才消费；取消不消费已有库存；可敲受阻块。零库存购买与取消后的库存语义按参考实现。加入敲击、碎片/缩放和音效，不能只瞬间 Destroy。

魔法棒：先模拟逐次移除选最多 6 块，允许“先 A 后 B 才可飞”的目标链；有目标才消费一次。参考是多颗星并行飞向目标，命中后缩放、移除再飞出，不是逐块等待 0.36 秒的六轮串行动画。每个目标只提交一次，工具锁释放、在途计数和最终结算必须一致。

计时：复核 `CanStartTimeFailTimer`、`ShouldTickTimeFailTimer` 的全条件。入场、引导、暂停、后台、弹窗与恢复按参考规则处理；不得因为普通块飞出而无条件暂停计时，导致快速点击可无限拖长限时。

## 7. 操作与演出还原

### 7.1 飞出

参考采用加速移动，默认初速度 6.24、加速度 15、上限 13，参考相机半高为 5；按当前 cameraSize/5 调整速度。目标当前固定 0.36 秒 cubic-out 并全程淡出，会呈现不同节奏，应替换。

UGUI 可保留，但必须建立参考世界单位到 Canvas 局部单位的换算：按实际可见区域和 Canvas 缩放推导，确保相同归一化屏幕距离的耗时一致。不能直接把 6.24 当像素/秒。终点应超过当前可见视口加方块边界，不能只固定移动棋盘边长 1.15 倍导致大块还在屏幕中消失。

保留体色与箭头直到飞出视口，拖尾与移动方向一致并正确释放。正常点击参考调用的 `playLaunchWindup` 为 false；虽然有 0.09 秒、0.09 格回拉辅助函数，不应把它强行加到每次点击上。

### 7.2 误点

- 朝箭头方向移动至障碍前，撞击挤压，再回原位；没有前进空间也要有撞击反馈。
- 前进时长为 clamp(0.08 + 0.06 * sqrt(距离格数), 0.12, 0.24)；回位时长为 clamp(0.12 + 0.04 * sqrt(距离格数), 0.16, 0.28)；撞击 0.05 秒。
- 距离计算只计真正空格，不计本块占格。当前目标 TryGetWrongMoveDistance 对自身格也 empty++，要修正。
- 参考错误箭头 0.04 秒间隔闪 3 次，并维持 WrongMarked 视觉；目标当前短暂红框+左右抖动不足以还原。
- 重复误点不扣心但仍反馈；同节点不能并发启动多个位置动画造成漂移。误点期间输入锁在回位后按当前局状态释放。
- 最后一颗心耗尽后，按参考碎心演出延迟 0.58 秒打开失败层，立即阻止新的有效操作。

### 7.3 提示、工具、入场与通关

- 提示闪烁色 #83F851，两轮，每个渐入/渐出阶段 0.2 秒；参考提示收集排除了箭头渲染，照实际行为适配 UGUI。结合 0.7 秒目标聚焦，不用长时间放大呼吸替代。
- 魔法星路径 1 秒，默认同时出发；命中目标放大至 1.15，再恢复，两段各 0.12 秒，再飞出。特效资源缺失时做本地几何占位也应保留节奏，不引入素材下载依赖。
- 锤子对齐命中声音延迟 0.35 秒，敲击/碎片时机参考实际协程；2.1 秒特效寿命不等于必须锁输入 2.1 秒。
- 入场 0.9 秒，由 0.68 倍缩放至正常，入场输入延迟基线 1.02 秒。切关和重开不会留下旧动画锁。
- 通关先等在途演出，展示关卡关联的完整图片并记录收藏，再进入可继续的结算。不用章节拼片替代原有单关完成反馈；现有章节页可保留导航功能。
- 声音/震动开关实际控制点击、误点、锤子命中和通关触发；缺平台震动能力安全降级，不把日志算作已还原音效。

### 7.4 触控与缩放

- 棋盘点选按占格/真实块轮廓命中，不把 L/T 块包围盒空洞误算作块；邻近候选的可动偏好、距离、排序层与 runtimeIndex 决胜规则对照 TapSelector 及调用参数。
- 默认近邻搜索比例 0.45、可动评分 1、受阻评分 1.5 来源于参考 Board 常量；必须结合实际调用核对，不能简单扩大所有矩形热区。
- 补齐游戏棋盘拖动/缩放；目标现有 PinchZoom 用于作品展示，不能直接认定游戏棋盘手势已经完成。
- 拖动与双指手势不能触发方块点击；手势结束后至少按参考 0.16 秒抑制点击。双指变单指不跳位，全部松手后才开始新点击。
- UI 按钮、弹层、暂停层阻止穿透；缩放前后箭头和块都能准确命中，按安全区适配不同纵横比。

## 8. 本地关卡与内容

用户要求自己先建本地 JSON，不依赖 CDN。除 GameplayConfig 外，交付本地关卡清单、每关 JSON 和图片关联配置。

优先沿用目标现有路径，减少无关迁移：

```text
Assets/Resources/BlockOut/GameplayConfig.json
Assets/Resources/ArtOut/GameAssets.json
Assets/Resources/ArtOut/Levels/<levelId>.json
Assets/Resources/ArtOut/ArtOutPictureConfig.json
```
