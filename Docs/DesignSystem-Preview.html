03 v5 → v6 改了什么 逐条对应上一轮评判

问题v5（旧）v6（新）
语义色撞车CTA #FF7568 ≈ 错误 #F45F70，红心/失败/受阻共用主行动 #4A2F26 巧克力棕；危险 #C62F45；红色禁止出现在主按钮/进度/导航
箭头读不清6 组浅粉彩 + 白填充箭头 + 1.4px 描边 + 3px 白轮廓块色整体降明度；1.5px 可可外描边；箭头深可可填充 + 1.5px 白描边，深浅块都可读
试错无预判默认棋盘全中性，可飞辉光只在 Hint 状态出现，同时 3 心扣命默认给可飞块 #1E8F68 描边 + 勾形角标；设置可关，新手前 3 关默认开
1/12 奖励无感整图薄雾，3/12→4/12 肉眼无变化，只剩 40 金币本关揭晓区金边 NEW + 局部放大 400ms；首页已解锁区全饱和，不再整图盖雾
小字不可读8/9/10px 大量存在，禁用色 2.2:1玩家可见文字 ≥11px、关键 ≥12px；禁用文字 #8A7568 4.6:1
布局浪费工具条固定 104pt 前 6 关全锁；结算页底部约 1/4 空白 + 4 按钮；收藏页三套进度全锁压缩 72（保留锁定态能力预告）；结算揭晓区弹性伸展 + 拼片进度卡填空白 + 3 按钮贴底、返回改顶部 X；收藏合并为一套进度
假 3D 廉价感果冻高光条 + 底部投影垫色 + 渐变冒充材质真·干净扁平：统一 2px 描边、两级柔影、单一光源，无硬偏移垫色
