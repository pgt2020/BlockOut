# 玩家体验整修 · 2026-11-17

用户要求按完整小游戏体验检查并直接修改，涵盖 UI、玩法、手感和完整流程。视觉选择为用户委托下的自主取舍，不等于用户已经认可最终美术。

## 已修正

### 界面与可读性

- 正式页面移除所有全屏参考稿覆盖：不再显示固定奖励、固定完成图、假皮肤商店或假图库。
- 首页保留现有画室美术，收敛为关卡、道具、设置和开始；隐藏未实现的每日和成就。真实关号、章节通关数量与金币均由档案驱动；金币加号有明确说明。
- 修复拉伸 RectTransform 把最终宽高写成 sizeDelta 的错误。顶部 HUD、托盘、道具卡、提示文字和首页金币恢复正确位置与尺寸。
- 拆开三个道具角标的 Image/Text 与重复 CanvasRenderer，消除 Unity 实例化断言。
- 原生按钮文字与按钮区域同步；修正微小字号、导航名称和当前页高亮。魔法不再用炸弹图标误导玩家。
- 结算保留真实图片、真实奖励与进度，增加独立浅色画框，主按钮改为克制的深绿。像素图片采用 Point 采样，消除模糊。
- 修复 Toast 根节点、宽度和位置，弹窗出现时清除旧提示；背景铺满，不暴露其他长宽比的相机底色。

### 玩法与手感

- 30 种贴图轮廓对照 C# 规则表逐格检查，修复 19 种上下方向错误。可见形状、箭头、透明洞和点击占格一致。
- 首批小棋盘适当放大，减少空旷感和过小命中目标；大棋盘继续按可用区域缩放。
- 捏合改为双指距离比，避免不同设备 DPI 造成相同动作、不同缩放幅度。
- 受阻提示缩短并节流，避免每次点击都刷屏；保留碰撞、音效及扣心逻辑。
- 修复规则层 CanMove 对已移除方块仍返回可移动的问题。
- HUD 进场/退场覆盖进度与提示元素，恢复半局按原始方块总数计算进度。

### 完整流程

- 关卡格排在章节长列表之前，支持当前未完成关卡继续；已通关格显示全局关号，未来关卡继续锁定。
- 全部关卡完成后首页提供重玩，不剩不可点的开始按钮。
- 暂停不再覆盖胜利、失败和已有模态；支持 Esc/Android 返回按层级关闭次级页面。
- 失败延迟弹窗校验对局令牌，防止跨局弹出；购买确认也改用对局令牌。
- 复活说明与实际恢复心数/时间一致；复活解除切后台留下的暂停锁。
- 结算保存失败提示可见，阻止跳回首页/关卡覆盖待保存结果，提供重试；重试不重复发奖。
- 商店显示每包数量、价格、未解锁和金币不足，不再只写含糊的“禁买”。
- 相机/EventSystem 已挂在持久根节点下，不重复调用无效的 DontDestroyOnLoad。

## 检查与证据

- Unity 版本：6000.2.7f2，与 ProjectVersion 保持一致。首次尝试用了另一已安装版本，发现包自动升级后立即停止并还原 manifest；最终锁文件与原版本一致，没有保留引擎/依赖升级。
- Unity EditMode：75/75 通过，无跳过。修正两条旧测试的不合法局面假设；图片资源检查从占位 Ignore 改为实际加载验证。
- Unity PlayMode：`BlockOutPlayerJourneyTests` 的三个完整流程，使用内存存档，验证引导、真实页面、半局恢复、暂停、通关、关卡更新、失败复活、提示/锤子/魔法、购买、退出确认，以及故障注入后的结算重试与奖励幂等。
- 606 关、125,947 个方块：边界、重叠、箭头与无道具可解性检查无失败。30 种贴图中心占格与规则表一致。
- UI 静态检查通过。修复首页检查器误选包内同名 Image 类型、将拉伸负 sizeDelta 误当负尺寸的问题。
- 真实 Unity 渲染图与 XML 位于 `design/ui/player-polish-20261117/`。图为测试内相机渲染，非手机截图；覆盖 390×844、360×640、390×932。
