### 参考工程启动方式（仅借鉴组织，不搬 TK）

**可借鉴**：进度字典式启动步骤、显式 Prefab 加载计划。
**不借鉴**：`Global.UseTest/UseLog` 静态开关直落业务、TK 登录与用户服务依赖。

## 10. 基线结论

1. 启动链是"运行时自动创建 + 空场景"，需要改为"Launcher 场景 + 唯一 AppRoot"（R03）。
2. 模块边界已由 asmdef 划定，缺 Bootstrap 与 Infrastructure 层（R08/R09）。
3. 无广告/统计 SDK，`IAdProvider` 已就绪，LevelPlay 适配只差 SDK 包与凭据（R14）。
4. 旧华容道代码 11 个文件可清理（R21，需 Unity 侧二次确认）。
5. 存档键/关卡 ID/hash 为硬契约，重构只做读写路径与事务化，不改结构（R13/R23）。
