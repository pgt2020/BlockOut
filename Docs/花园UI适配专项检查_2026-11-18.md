# 花园UI比例与适配专项检查

检查方式：直接读取Prefab、TextureImporter、注册表和布局代码，数学模拟安全区与等比缩放；没有调用Unity或执行运行测试。

## 图片

检查124个花园素材Image引用。Simple类型均保留比例；Sliced仅用于panel/button/pill/frame类型底板且有非零border。背景为等比覆盖，允许边缘裁切，不是把插画压扁。动态结算图片在控制器中设置preserveAspect=true。没有发现检查范围内直接不等比拉伸插画或图标的配置。

九宫格会拉伸中心和边缘中段，这是底板的预期行为，不能与图标整体变形混为一谈。运行中的抗锯齿、边框细节仍需实际看图。

## 界面完整性

注册表实际5个页面：加载、首页、对局、关卡、道具。
7个弹层：暂停、失败复活、确认、结算、设置、关于、引导。
共12个正式界面，全部启用安全区布局。先前18个Prefab包括5个动态列表模板和1个公共弹层容器，不等于18个独立页面。

所有固定可见文字/按钮的设计边界检查无越界；自动布局与滚动内容需运行验证，未被此检查错误地计为实际验收通过。

任务、成就、每日、皮肤属于未新增的玩法，不在已完整接入的现有界面范围内。发布平台的隐私/授权流程也未在本轮验证。

## 屏幕适配的实际范围

当前为390×844设计面整体等比适配到安全区，不是对不同屏幕逐个重新排版。

- 360×640：内容缩为约295.7×640，左右各留32.1像素，由背景填充；16设计像素文字约12.1屏幕像素，12设计像素约9.1。不会因此图片变形，但辅助文字与小按钮会变小。
- 390×844无安全区：原设计比例。
- 390×844，上47/下34安全区：内容约352.6×763，位于安全区内。
- 390×932，上47/下34：内容390×844，额外纵向留白由背景填充。
- 768×1024，上24/下20：内容约452.8×980，左右留白较多。

数学模型未发现设计面越出这些安全区。不能据此声称小屏点击舒适性、动态文案、横屏或所有设备已经验收。尤其360×640辅助文字较小，应作为用户运行验收的优先项；平板目前是竖版居中模式，不是专门平板版式。
