# 全界面与流程复查

范围：12 个正式页面/弹层及动态道具、关卡、章节条目；检查入口绑定、弹层返回、关卡进入、失败复活、结算、购买、存档失败分支和静态布局。遵循用户偏好：不启动 Unity 验证。

## 本轮已修正

| 区域 | 原问题 | 修改 |
| --- | --- | --- |
| 关卡页 | 从列表下部选择章节，关卡网格仍留在视野外；同章点击无反馈 | 重建布局后停止惯性并回到顶部；同章点击也回到选择区；当前章轻度高亮 |
| 关卡页 | 无通关记录时提示“完成第一关后再来”，与实际允许开始当前关矛盾 | 区分当前章可开始、未来章待开启；章节可选状态也检查数据存在 |
| 失败页 | 无钱且广告未就绪被误判为耗尽复活资格，后续广告就绪也可能不更新 | 资格与支付/广告状态分开；每 0.25 秒使用非游戏时间刷新；等待回调禁用复活按钮 |
| 失败页 | 广告旧回调可以在新对局显示提示或关闭弹层 | UI 回调增加对局令牌和当前失败层检查；失败文案不再把保存失败都称作广告未完成 |
| 结算 | 下一关校验前关闭结算，失败后可能只剩完成棋盘 | 先检查下一关，成功切屏时才清层；统一入口增加未保存结算保护 |
| 弹层 | 暂停、设置、关于层叠加；显示顺序取决于创建顺序 | 设置替换暂停、关于替换设置，返回恢复原上下文；新弹层置顶且 Toast 保持最上层 |
| 页面切换 | 非棋盘页面切换可能残留旧弹层 | 所有切屏清理弹层；玩法说明响应返回键 |
| 首页 | 全通关“再玩一局”和提示被常规文本覆盖 | 重玩显示明确“重玩第 N 关”，保留全通关和下一章提示 |
| 购买 | 固定延迟偏长，等待受游戏计时影响，成功只说“购买成功” | 非游戏时间等待 0.15 秒，成功说明道具与数量；金币同步关卡页 |
| 界面 | 关于、玩法说明、失败窗空旷；文字与按钮过小 | 收紧窗口；缩短道具说明；修正文字容器；购买按钮 104×48，结算次级按钮高 48 |

失败窗 342×386、关于窗 342×272、玩法说明窗 342×320，保持现有暂停和设置的紧凑布局。去掉窗外漂浮装饰，避免装饰不随窗口中心缩放。没有改变道具价格、奖励数值、关卡颜色、关卡解锁顺序或存档格式。
