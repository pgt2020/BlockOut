# BlockOut (经典华容道 / Unblock Me) 2D 益智滑块游戏

> **历史版本说明（2026-10-14）**：本文只说明当前目录内的旧华容道脚本，不代表 BlockOut 的新产品目标，也不代表完整 Unity 工程已就绪。新目标是参考 ArtOut 的箭头消除与图片收藏；请从 `产品方案PRD.md`、`AI开发实施规格.md` 和 `UI原型/design_v3_final/README.md` 开始。当前目录缺少 `ProjectSettings`、`Packages` 和已生成的主场景。

这是一个基于 Unity 引擎完整开发的 2D 华容道（Unblock Me 风格）益智解谜拼图游戏。游戏拥有高雅的天然木质与雅致美学风格，提供 10 个精心设计且难度递增的经典关卡。项目采用**纯代码驱动与零外部素材依赖（Zero-Dependency）**设计，所有方块、棋盘底板、出口标识、星级图标、UI 界面、粒子庆典特效以及交互音效均在运行时程序化动态生成，开箱即玩！

---

## 一、游戏核心玩法与特性

- **6x6 网格棋盘**：严谨的网格占用与滑动约束系统。
- **单轴向物理阻挡滑动**：
  - 横向方块（尺寸 2x1, 3x1）仅可在水平 X 轴平滑滑动。
  - 纵向方块（尺寸 1x2, 1x3）仅可在垂直 Y 轴平滑滑动。
  - 无法相互穿透或越过棋盘边界。
- **目标方块与出口判定**：
  - 红色核心目标方块位于第 3 行。
  - 移开所有障碍方块，将红色目标方块滑动至右侧出口通道即可获胜。
  - 通关时触发方块飞出动画、彩带漫天喷射、星级评定与胜利号角！
- **平滑动画与吸附系统**：基于原生 Unity 协程（Coroutine）实现的缓动动画（Ease-Out），松开手指时自动吸附至最近网格中心，无需任何 DOTween 等第三方插件。
- **完善的辅助系统**：
  - **无限撤销（Undo）**：记录每一步方块移动轨迹，随时回退错误操作并友好扣减步数。
  - **关卡提示（Hint）**：高亮并呼吸式脉冲闪烁目标方块，指引破局关键。
  - **星级评价（1~3星）**：根据完成步数实时动态评定星级，挑战最少步数极限。
  - **关卡进度持久化**：使用 `PlayerPrefs` 自动保存已解锁关卡、最高星级与历史最佳步数。
  - **纯程序化音频系统**：内置声波合成器生成木块拾取、吸附碰撞、滑动、按钮点击、通关琶音与背景轻音乐。

## 三、快速上手与运行指南

### 方式 1：使用 Unity 编辑器菜单一键配置（最推荐）
1. 在 Unity 编辑器顶部菜单栏找到 **`BlockOut`** 菜单。
2. 点击 **`BlockOut -> 一键配置全部 (场景 + 关卡资源)`**：
   - 自动生成 `Assets/Scenes/MainScene.unity` 场景；
   - 自动在场景中创建启动引导器 `GameSetup`；
   - 自动生成 10 个关卡的 ScriptableObject 资产至 `Assets/Resources/Levels/` 并在 Build Settings 中注册场景。
3. 点击 Unity 编辑器的 **`Play` (运行)** 按钮，即可开始畅玩！

### 方式 2：在任意空场景中直接挂载
1. 在 Unity 中新建一个空场景。
2. 创建一个空 GameObject（例如命名为 `Bootstrap`）。
3. 挂载 `BlockOut.GameSetup` 组件。
4. 点击 **`Play`** 运行，`GameSetup` 将自动检测并动态创建正交相机、EventSystem、棋盘网格、UI 画布与所有系统单例！

## 五、技术亮点与设计哲学

1. **零外部美术依赖 (TextureGenerator)**：
   - 算法计算每个像素距离几何形状边缘的欧氏距离，实现平滑抗锯齿边缘（SDF-like Anti-aliasing）。
   - 针对不同朝向与长度的方块，自动调配暖橡木、胡桃木、红木的渐变色彩与顶部环境内发光。
   - 纯代码算法绘制五角星、出口门洞指示箭头与圆角按钮。

2. **零外部音频依赖 (Procedural Audio Synthesis)**：
   - 使用 `AudioClip.Create` 与波形数学公式合成木材质感音效：
     - 拾取：400Hz 到 650Hz 正弦波瞬时上滑与高斯包络。
     - 敲击：220Hz 衰减正弦基波与 440Hz 泛音合成。
     - 通关：C5-E5-G5-C6 清脆和弦琶音。
     - 舒缓 BGM：中国传统五声音阶算法循环。
   - 亦开放 Inspector 槽位，方便美术或策划随时替换为真实 WAV/MP3 音频。

3. **零外部插件依赖 (DOTween-Free)**：
   - 依托 Unity 原生协程与 `Mathf.SmoothStep` / Ease-Out Quad 缓动函数实现所有移动、吸附与星星弹出动画，避免引入任何第三方付费或繁重插件。

4. **解耦的架构设计**：
   - 严格遵循单一职责原则，采用 C# 原生事件委托机制驱动视图更新，确保核心网格逻辑（`GameBoard`）与业务管理（`GameManager`）、界面（`UIManager`）完全解耦。

## 六、扩展与自定义指南

### 1. 添加新的关卡
在 `Assets/Scripts/Core/LevelManager.cs` 的 `CreateBuiltinLevel` 中添加分支，或直接在 Unity Project 窗口中右键：
`Create -> BlockOut -> Level Data`，在 Inspector 中可视化配置方块的坐标与尺寸，保存至 `Assets/Resources/Levels` 目录下即可自动被游戏载入。

### 2. 更换自定义美术或音效
- **材质/外观**：可在 `Block.cs` 的 `Initialize` 或 `GameBoard.cs` 中直接绑定外部 Sprite 资源。
- **音效**：在场景中的 `AudioManager` 物体 Inspector 上直接拖入你喜爱的音效文件即可，系统将优先播放外部文件。
