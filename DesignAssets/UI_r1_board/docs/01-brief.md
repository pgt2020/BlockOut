# 视觉简报（R1 · 对局页）

## 设备与视口
- 设计档 **1080×1920**（与项目 `BlockOutLayoutMetrics` 的 390×844 pt 基准同比例，缩放系数 2.769）
- 安全区：上 96 / 下 88 / 左右 40（设计像素）
- 触控目标全部 ≥ 120px 设计像素（≈43pt），暂停键 96px 见方

## 玩法事实（不得虚构）
- 玩法：点击方块，方块沿箭头方向整块飞出；通路被其他方块挡住则不能飞。
- 棋盘：来自真实关卡 JSON，多格连体、足迹非矩形、每块只有一个箭头。
- 生命：3 颗心，连错只扣 1 颗，用完才结束（可复活）。
- 道具：提示 / 锤子 / 炸弹三件，本轮显示计数 3 / 2 / 1（沿用原版对局页的实际数字）。
- 进度：已飞出块数 / 总块数。
- **没有**货币、商城、体力、签到、赛季——本轮一概不出现。

## 首要视觉中心
1. 棋盘（占屏面积约 45%，是绝对主体）
2. 顶部关卡号 + 生命 + 进度
3. 底部三件道具

## 五项具体视觉特征
1. **容器三层**：页面（暖奶油 + 极轻纸纹）→ 奶油卡（近白、厚 22、倒角 9）→ 点阵板（深一档奶油、内阴影、26px 点阵）。层级靠明度和内阴影，不靠描边堆叠。
2. **方块是连体厚块**：同一块的多个格子共用一个外轮廓，只在外轮廓倒角（半径 = 0.30 格）；块与块之间留 3.2px 真缝，缝里落阴影。
3. **单一光源**：主光在左上偏前（0.33, 0.88, 0.70），投影统一落向右下；补光极弱（0.42），只用于不让暗部死黑。
4. **材质哑光**：roughness 0.58、clearcoat 0.14、envMapIntensity 0.45。**无渐变贴图、无硬投影垫色、无顶部白色高光条。**
5. **箭头是同一造型**：白色 #FFFCF4，尺寸 = 0.60 格，挤出 5px 后自身投一道贴身阴影 —— 靠影子读形，不靠描边。

## 色彩角色
| 角色 | 值 | 用途 |
| --- | --- | --- |
| 页面底 | `#FFFAF2 → #F1DEC2` 径向 | 背景 |
| 奶油卡 | `#FFFCF6` / 侧 `#E3CEAD` | 棋盘容器、道具卡、暂停键 |
| 点阵板 | `#EFDCC0` | 棋盘承托面 |
| 主文字 | `#3B2A24` | 关卡号、道具名 |
| 次文字 | `#6E5449` | 副题、提示、剩余块 |
| 进度 | `#1E8F68` | 已完成部分（唯一绿色） |
| 生命 | `#D93A4E` | 只用于心，不用于任何按钮 |
| 方块 | 关卡色相 → DesignSystem 6 组，饱和度 ×1.22 | 棋盘 |

**禁令**：红色不做主按钮；金色不做装饰性描边；不在同一屏出现第三套进度表达。

## 禁止特征
- 网页版式：标题+副标题+卖点卡片+统计数据+页脚
- 仪表盘：数据卡、环形图、双栏信息
- 假 3D：`0 7px 0 #xxx` 硬投影垫色、纯 CSS 渐变冒充材质、border 三角
- 塑料感：处处镜面高光、彩虹渐变、胶囊按钮满屏
- 装饰替代信息：为显得丰富而加图标、加角标、加光效
