# INKROOM / 油墨间 · BlockOut UI 概念稿

> 2026-11-12 · 独立视觉方向，不沿用 v6/v7 的奶油圆润风格
> 静态设计稿，未接入 Unity、未编译、未运行。

---

## 1. 概念

把每一关当成一次**印刷**：

- **方块 = 油墨**，箭头是它必须离开的方向
- **通关 = 印成一张画**，结算页是"印张揭晓"
- **图库 = 印张档案**，章节是"校样表"，收藏是"版本号"
- **皮肤 = 油墨套装**，只换墨色，不换判定

视觉语言借用印刷工作室：纸张白、墨黑硬边框、限定油墨色、宋体大标题、等宽版号、裁切线、套印错位。  
目标是让"方向 / 边界 / 可飞"这类**信息**永远压过装饰，同时把"收集一张画"的长线目标做成看得见的东西。

## 2. 设计 Token

### 纸张与墨
| Token | HEX | 用途 |
| --- | --- | --- |
| `paper` | `#F2EDE2` | 页面底色 |
| `sheet` | `#FBF8F0` | 卡片 / 印张纸面 |
| `paperDeep` | `#E5DECD` | 图表底、压暗区 |
| `ink` | `#15171B` | 主文字、硬边框、主按钮 |
| `ink2` | `#3D4047` | 次级文字 |
| `ink3` | `#6C6F76` | 说明文字、版号 |
| `rule` | `#CFC7B6` | 细分割线 |
| `rule2` | `#A9A192` | 虚线、锁定边框 |

### 限定油墨（语义固定）
| Token | HEX | 语义 | 允许用途 |
| --- | --- | --- | --- |
| `vermilion` | `#D5432A` | 危险 / 损失 / 套印重影 | 错误描边、生命耗尽、失败 |
| `cobalt` | `#1F3FA8` | 当前 / 进行中 / 数据 | 当前关卡、"在印"、成就进度 |
| `gold` | `#E3A518` | 奖励 / 新揭晓 | NEW 角标、今日、金币、印章高亮 |
| `sage` | `#2F7D5B` | 可飞 / 成功 | 可飞描边与勾、成功文案 |
| `lilac` | `#7A5AA6` | 扩展油墨 | 方块第六色 |
| `ink` | `#15171B` | 主行动 | 主 CTA、激活导航 |

硬规则：**红不用于主按钮**；主行动永远墨黑底 + 纸白字；状态必须同时有形状/文字，不只靠颜色。

### 方块六色
朱砂 `#D5432A` · 钴蓝 `#1F3FA8` · 芥黄 `#E3A518` · 墨绿 `#2F7D5B` · 紫 `#7A5AA6` · 纸灰 `#E9E1D0`  
统一 1.5px 墨黑描边 + 内侧 1px 浅色线；箭头在深色墨上反白、在芥黄/纸灰上转墨黑。

## 3. 字体与尺寸

| 层级 | 字体 | 字号 / 字重 |
| --- | --- | --- |
| 页面大标题 | 宋体 / Georgia | 28–32 / 700，字距 .08em |
| 弹窗标题 | 宋体 | 26–27 / 700 |
| 印张名 | 宋体 | 12–15 / 700 |
| 正文 / 按钮 | 黑体 | 11–15 / 400–700 |
| 微标签 / 版号 | 等宽 | 7.5–9，字距 .12–.24em |

- 8pt 栅格：`3 / 6 / 9 / 12 / 16 / 20 / 24`
- 屏边距 20（对局棋盘 18）
- 圆角：0–2（纸片感），只有胶囊/圆点使用全圆
- 描边：主框 1.5px 墨黑；分割 1px `rule`；锁定 1px 虚线
- 阴影：只在"可交互的纸片"上用硬投影（`4–6px` 同色偏移），其余全部无阴影
- 触控目标 ≥ 44×44

## 5. 动效建议

| 场景 | 时长 | 缓动 |
| --- | --- | --- |
| 页面转场 | 200ms | ease-out |
| 方块飞出 | 320ms | cubic-bezier(.2,.8,.2,1)，可加墨点拖尾 |
| 错误 | 240ms | 水平 ±5px 衰减 3 次 + 朱砂闪一次 |
| 新片揭晓 | 360ms | 金框 1.06→1 + 淡入 |
| 弹层 | 180ms | 上滑 20 + 淡入 |
| 印章落下 | 180ms | scale 1.3→1 + 轻微旋转 |

尊重系统"减少动态效果"：关闭后只保留颜色/状态切换。

## 6. 与现有工程的关系

这是**全新视觉方向**，与 `Docs/DesignSystem.md`（v6）和 `DesignAssets/UI_v7` 不共享 Token，也未改动任何 Unity 资源。

如果采用，需要新建一套独立 Token 与 Prefab，不复用 v6 的 `BlockOutDesignTokens` 数值。页面对应关系：

| 概念稿 | 现有 View |
| --- | --- |
| 02 首页 | `BlockOutHomeView` |
| 03 对局 | `BlockOutBoardPageView` + `BlockOutBlockNode` |
| 04 结算 | `BlockOutSettlementView` |
| 05 图库 | `BlockOutCollectionView` / `BlockOutChapterItemView` |
| 06 章节地图 | 章节列表 / `BlockOutRepeatItemView` 可扩展为校样表 |
| 07 失败 | `BlockOutFailView` / `BlockOutPauseView` |
| 08 皮肤 | 现有皮肤层 |
| 09 每日 | 每日任务 / 成就层 |

棋盘表现层需要单独处理：方块颜色应来自**新六色 Token 的重映射**，而不是直接使用关卡 JSON 的 `color`（保持 ArtOut 数据字节级兼容）。

字体落地需要随包引入一套中文宋体（如 Source Han Serif）与等宽字体；当前稿在 Windows 上以 SimSun / Courier New 近似。
