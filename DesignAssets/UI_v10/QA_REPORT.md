# UI v10 重做自检记录 —— 对齐第一版原图

## 为什么重做

v9 方向错了：我把第一版的「**真实3D场景背景 + 厚软胶UI浮层**」做成了「程序化点阵底 + 扁平卡片」，节点、吉祥物、悬浮圆钮全丢了。第一版两张原图才是准绳。

## 参考基准
- 关卡地图原图：3D花园拱廊场景；灰锁40/39、紫星38、绿当前37带"当前关卡"气泡、红36/挑战带骷髅；黄色方块吉祥物(眼/腮红/手脚/绿箭头)；任务/成就悬浮圆钮；绿色"第37关"大按钮；底部4个独立卡片tab。
- 9屏原图：加载(3D画廊走廊+四色箭头logo)、主页(画架像素画+悬浮钮)、图库、游戏(满棋盘软胶方块)、结算、失败弹窗、皮肤、每日。

## 做法
1. **背景**：生成两张3D软胶渲染场景（花园关卡地图、画廊走廊），裁掉右下水印后铺满。这一步是关键——程序化画不出第一版的光影/景深/材质。
2. **UI浮层**：写 `clay_block()` 厚软胶组件（外描边+顶部高光带+底部暗边+柔投影），关卡节点/按钮/卡片统一用它。
3. **游戏棋盘**：满盘异形排布彩色软胶方块带箭头（复用 tile_kit 光照思路）。
4. **吉祥物/图标**：全部矢量绘制（爱心用参数方程、齿轮/票券/锁/星/房子/图库/调色盘/日历），不依赖 emoji 字体。

## 自检收敛（3轮）
- **第1轮**：9屏生成后对照原图 → 发现方向对但6处问题：游戏页标题牌与心重叠、道具emoji显示成空白方块、失败弹窗红心成方块、结算"首页"文字重影、挑战节点文字被角标挡、多处emoji豆腐块。
- **第2轮**：标题牌上移、道具改文字符号、挑战角标改"!"、结算降字号 → 对照发现：心形渲染成蝴蝶结状、地图页emoji(齿轮/票券/锁/星/底栏图标)全变豆腐块。
- **第3轮**：写矢量图标函数替换所有emoji；爱心改参数方程画饱满心形 → 复核达标。
