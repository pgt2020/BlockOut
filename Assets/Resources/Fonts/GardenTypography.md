# 花园 UI 字体

标题、关卡数字、按钮：ZCOOL KuaiLe Regular（站酷快乐体）。
正文、条件、计时和较长提示：Source Han Sans CN Regular（思源黑体）。

站酷快乐体来自 Google Fonts 官方仓库：
https://github.com/google/fonts/tree/main/ofl/zcoolkuaile

源文件：https://raw.githubusercontent.com/google/fonts/main/ofl/zcoolkuaile/ZCOOLKuaiLe-Regular.ttf

许可：SIL Open Font License 1.1，随项目保留 ZCOOLKuaiLe-OFL.txt。字体未修改。导入配置保留字体数据，思源黑体作为缺字回退。UI 文本仍为可替换的真实 Text，不烘焙在图片里。

站酷快乐体仅用于较短展示文字；大段正文不使用。离线检查已覆盖已序列化标题的字符，运行时任意扩展文案仍需检查实际显示。
