## 针对审查意见的修订

1. **panel-cream**：主体由上版 540×834 提升到 678×920（接近目标 720×972）；中央改为均匀浅暖白，无纸纹/光斑/大渐变；左侧与底部棕粉残点已清除（重写色键判据 + 实测底色 despill + 低 alpha 归零）；奶油厚边保留。金细线较上版细软，但未完全去除。
2. **button-green**：改为真正的宽按钮，比例 3.25:1，主体放大到 715×220（上版 337×159）；去掉斜向高光，绿色为上下纵向渐变、横向中段均匀；宽奶油框为主。主体放大用等比缩放（圆角不变形）+ 透明补边，非拉伸。
3. **icon-hint**： metallic 强光泽改为温暖哑光玩具质感，螺纹简化、去刺眼高光；改为完全竖直居中；左右粉橙残边清除。最长边 211px（要求 196–216）。
