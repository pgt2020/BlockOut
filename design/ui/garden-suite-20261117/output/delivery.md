## 生成 / 处理方式

- 全部以 `input/style-reference.jpg` 为唯一风格参考；纯环境、无文字数字、无整页设计。
- 三张透明母版先在**纯洋红单一色底**上生成，再用颜色判据（G/R 或 G/B 偏高＝主体，低＝背景）做色度键，去色溢 + 边缘羽化 + 连通域过滤，得到真实透明 PNG。未使用白底删白，奶油厚边与暖金边完整保留。
- A01 右下角"AI生成 WORKBUDDY"水印用局部 inpaint 修复；源图 1072×1920，等比放大后左右各补 4px 到 1080×1920，未拉伸。

## 已知问题 / 取舍（如实标注）

1. **下方软阴影已去除**：投在洋红底上的深色阴影与背景同色系，无法色度分离；为避免脏边，选择保完整主体、去阴影。需要阴影时请在 Unity 侧用轻量 drop shadow 补回。
2. **边缘抗锯齿**：已做羽化，边缘有约 1–2px 半透明过渡带；个别像素可能有极淡暖色毛刺，正常显示尺寸下不可见。九宫格拉伸区（面板中心、按钮中段）干净无花纹。
3. **A01 左右各 4px 补边**：为凑精确尺寸，边缘为等比放大后的延展，不影响主体。
4. 未导入 Unity、未做运行验收（按项目约定不主动触发刷新/编译/Play）。
