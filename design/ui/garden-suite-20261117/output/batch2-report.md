- **A02 对局背景**：沿用 garden-home.png + 主参考风格重新生成，中央为低对比浅暖米色散焦区、花草只在边缘、柔和过渡无硬边矩形；无任何棋盘/UI/数字/文字。右下水印 inpaint 修复，源图左右各补边到 1080×1920（未拉伸）。
- **A05/A06**：以 button-green_v02 为底**程序化换色**——只替换绿色面层的色相，保留原亮度层次（立体光影）和全部几何/alpha。奶油=暖白→浅蜂蜜厚度；珊瑚=柔和橙红→深珊瑚。几何像素级继承母版。

- A07 额外用几何圆蒙版（圆心128,120、半径104）清除外圈粉橙残边，直径定到约 208px。
- 脚本：`output/source/process_batch2.py`；带底原图在 `output/source/`；三底预览在 `output/review/`。
