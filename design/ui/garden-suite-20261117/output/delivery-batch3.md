## 六、生成 / 编辑方式

- 背景：文生图（主参考 + garden-home 作风格输入）→ 本地去水印（inpaint）+ 等比补边到 1080×1920。
- 组件/图标/角色：纯洋红色键底生成 → 本地自适应色键抠图（阈值随每张底色偏色自调）→ 连通域清水印 → 实测底色 despill → 最近实心色扩散清边 → 尺寸归一。
- 换色件（A05/A06/A09/A10）：从母版只替换面层色相，alpha/轮廓逐像素不变。
- 碎心（A23）：基于完整爱心母版在中央加一条透明锯齿裂缝，未碎成多片。
- 圆底座（A07_v02）：因首轮局部修色粉边不彻底，重生成纯奶油暖金版本 + 几何圆蒙版，几何/圆心/直径与审查基准一致。
