# 三张必做 + 可选角色的 v02 修订交付

依据《全套素材审查与最后修订.md》。**只重做 frame-art / pill-cream / icon-lock 三张，另可选角色，其余 22 张已通过素材未改动、未覆盖。**

## 做法变更（重要）

- **画框与胶囊改为程序化重建**，不再依赖 AI 生图。原因：AI 源图的画框带棕黑金属条纹与多层金线、边缘有洋红残边，逐次去杂只能治表面，去不干净；且审查要求「严格正视对称＋奶油宽边为主＋单条淡金辅线」。改为用已通过的 `panel-cream_v02.png` **实测配色**（奶油边 RGB 249,233,216 / 淡金 RGB 224,180,112 / 暖白面 RGB 251,244,238）配合距离场倒角＋左上光源＋环境遮蔽绘制，几何上天然正交、对称、可量测。
- **锁与角色保留 AI 生图**（造型需要材质感），只做边缘净化：色键抠图 → 硬阈值去灰雾 → rim despill（把边缘像素色替换为内侧实心色）→ 双侧双边滤波降噪 → 降饱和。洋红像素：锁 24→0，角色 2254→0。

## 仍存在的问题（如实列出）

1. **画框外轮廓 23..745**，比要求的 24..744 各多 1px，来自抗锯齿溢出；若 Unity 九宫格按 24/744 切边会切掉不到 1px 的柔边，不影响观感。
2. **金线是柔和淡金细线，不是金属高光**。这是审查「减少多层金属金线」的直接结果；若后续想要更亮的金属感，需要单独加一层高光，本版未做。
3. **画框与胶囊的材质是程序化渐变＋轻颗粒**，没有 AI 生图的真实绒面/布纹。颜色与光影已对齐 `panel-cream_v02.png`，但放大到 4 倍看颗粒规律性弱于 AI 版。
4. **锁梁保持哑光暖灰**（非奶油色），与奶油锁身形成对比以保证深色底可读；这是刻意的，若要求整锁同色需再调。
5. **锁仍保留极细深色轮廓**（来自源图），用于深灰底上区分边界；不是灰雾残渣。
6. 角色为可选件，未参与整套风格统一性审查。
