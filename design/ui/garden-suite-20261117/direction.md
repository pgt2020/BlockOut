## 统一视觉规范
- 明亮蓝天、阳光花园、画廊与像素画世界；上下装饰形成纵深，中部服务玩法。
- 奶油白厚边、暖金次级边缘、圆润倒角、下方柔影；左上柔光，避免过曝高光。
- 主操作草绿到翠绿，辅助操作奶油色；失败/危险珊瑚色，锁定为暖灰。紫色只用于特殊关卡标记。
- 数字采用饱满白字加深色柔影；正文深咖。动态文案保持 Unity Text，不能烘焙进图片。
- 同一个按钮/面板/圆形图标基座跨页复用，状态只变明度与位移，不改变轮廓。
- 首页允许世界场景较丰富；对局棋盘中央必须安静清楚。花园保留在外围，不压过箭头和方块。
- 不用全屏设计图加透明按钮，不把既有错误切图再次铺回运行时。

## 页面覆盖
| 页面 | 构图与实现目标 | 真实交互 |
|---|---|---|
| 加载 | 花园背景、游戏标识、简洁进度槽 | 资源加载状态 |
| 首页 | 中央纵向关卡路径、凸起关卡按钮、底部大型绿色开始按钮 | 当前关卡、完成状态、金币、开始/继续、设置 |
| 对局 | 顶部奶油 HUD、清楚的心数/进度、中央棋盘托盘、底部三个立体道具按钮 | 现有真实棋盘、暂停、提示、锤子、魔法 |
| 关卡 | 花园底、奶油标题与章节面板、统一凸起关卡格 | 当前关卡继续、完成关卡重玩、锁定、滚动 |
| 道具 | 同一花园底、三张统一立体商品板 | 实际数量、价格、解锁条件、购买确认 |
| 结算 | 花园底、庆祝横幅、奶油画框中的真实完成图片 | 真实奖励、下一关、回首页、保存失败重试 |
| 暂停 | 暗化游戏背景、奶油厚面板、绿色继续 | 继续、重开、设置、退出 |
| 失败 | 同款面板、破心图标、绿色复活 | 实际复活条件/次数、重开、返回 |
| 设置 | 同款面板、清楚的开关行 | 音乐、音效、振动、关于、返回 |
| 确认 | 同款紧凑面板、双按钮 | 退出/重开/购买等实际确认文案 |
| 新手引导 | 同款面板、示意箭头方块 | 真规则文案、开始挑战 |
| 关于 | 同款紧凑面板 | 返回 |
| 提示/禁用/错误 | 统一奶油提示牌和暖灰状态 | 保存重试、购买结果、道具不足 |

参考中的任务、成就、每日、皮肤并非本项目已实现功能。不得显示无效入口或把道具标为皮肤；若扩展这些玩法需另行实现完整规则、存储和奖励。

## 资源清单与制作约束
1. garden-background：无 UI、无文字、无路径数字的竖屏花园插画；适配 9:16 至 9:21，上中部干净。
2. board-background：同场景的低细节版本；棋盘区域低对比。
3. panel-cream：透明独立厚奶油面板，九宫格安全边，无文字、图标、内嵌按钮。
4. button-green / button-cream / button-coral：一致外轮廓和厚度，无文字；九宫格边缘，按下态确定式生成。
5. tile-green / tile-purple / tile-grey：圆角方块关卡节点，无数字、锁、星、旁边背景。
6. round-base / coin-pill / toolbar-base：同材质；图标与数字分别叠加。
7. hint / hammer / magic / settings / home / levels / store 图标：统一光源与视角，透明边缘完整。
8. 完成横幅与相框：无文字，无固定奖励或内嵌关卡图。
9. 棋盘、箭头、文字、路径线、填充进度：原生动态，沿用有效数据。
