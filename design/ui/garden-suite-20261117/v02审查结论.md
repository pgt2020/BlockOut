# v02 母版审查

结论：通过本轮素材方向审查，可以继续延展。此为开发者素材审查，不等于用户最终审美认可或 Unity 运行验收。

实际检查了 v02 文件、透明通道、深灰/浅蓝背景显示、手机尺寸组合，以及裁去透明留白后进行的九宫格拉伸预览。原始 PNG 未修改，未导入 Unity，未运行或编译。

- panel-cream_v02.png：768×1024，可见边界 (44,48)-(722,968)，678×920。
- button-green_v02.png：768×256，可见边界 (26,18)-(741,238)，715×220。上一版主体过短的问题已解决。
- icon-hint_v02.png：256×256，可见边界 (59,19)-(198,230)，139×211。32/48/64 像素显示仍能辨认。
- 以上包围盒采用右/下边界不包含的像素坐标。
- 外部有真实透明 alpha。深浅底下未见上一版那样明显的粉色污染和面板散点。

## 仍需注意

- 面板中心仍有轻微纹理和明暗，不能称为纯色。当前弹窗尺寸拉伸可用；不宜无限大拉伸。棋盘托盘可在接入时使用平整内层，保证游戏可读性。
- 按钮奶油边缘仍稍有毛糙，正常手机尺寸弱化，后续可做局部边缘修整。不要继续放大作为高分辨率横幅。
- 灯泡为简化的黄色实心玩具形态，图标系列应统一该语言，不回到 v01 金属高光。
- 阴影已被制作方移除，运行时需统一补软阴影；不可把残留底色作为阴影。
- 九宫格参数须结合裁边、实际目标尺寸确定，不直接套第一版建议。
