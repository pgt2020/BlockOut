# BlockOut 关卡生成器说明

## 目录约定

本目录按来源拆分两套工具：

- `ArrowOut/`：完整的图片到 ArtOut 关卡 JSON 生成管线，并附带原项目的 C# 随机关卡生成器参考实现。
- `TapGallery/`：TapGallery 的方向求解工具，用于给已有网格或图片分配可解的箭头方向。

两套工具都放在 `Tools/` 下，属于离线关卡制作工具，不会在游戏运行时自动生成关卡，也不会自动修改 Unity 场景。

## ArrowOut 生成管线

### Python 图片生成器

入口是 `ArrowOut/generate_artout_levels.py`。它的处理过程是：

1. 读取输入图片并按尺寸缩放成像素网格。
2. 根据透明度判断哪些格子有内容，同时采集颜色。
3. 使用 `board_splitter.py` 和 `artout_shapes.py`，把填充区域覆盖成形状库中的方块。
4. 计算每个方块的坐标、形状编号、颜色和箭头格。
5. 分配能够逐步移出棋盘的方向，并用可解性规则检查布局。
6. 输出关卡 JSON，以及图片配置和可选的纹理文件。

常用命令：

```powershell
python Tools/LevelGenerators/ArrowOut/generate_artout_levels.py input.png `
  --output-levels Assets/Resources/ArtOut/Levels `
  --output-picture-config Assets/Resources/ArtOut/ArtOutPictureConfig.json `
  --picture-id sample --chapter 0 --levels-per-picture 12
```

复制后的脚本保留了 ArrowOut 的原始字段和算法。执行时建议显式传入输出路径，避免把文件写到其他工程目录。

`generate_levels_from_config.py` 用于根据已有图片配置中的 `shapeRows` 重新生成现有关卡；`audit_levels.py` 用于检查边界、重叠、形状编号和方向数据。

### C# 随机生成器

`ArrowOut/UnityRuntime/ArtOutPieceLevelGenerator.cs` 是原项目的 C# 生成器参考实现。它可以按关卡数量生成不同尺寸的棋盘，随机摆放不重叠方块，并根据方块位置分配方向。

这个副本放在 `Tools` 下，默认作为算法参考，不属于 BlockOut 的运行时程序集。若要在 BlockOut 编辑器中直接调用，需要把代码适配为 BlockOut 的数据类型和命名空间，再单独加入 Editor 工具入口。

## 生成全是单格方块的关卡

BlockOut 的形状库中，`shapeId: 1` 表示占用一个格子的方形方块。要生成“全部由单独小方块组成”的关卡，应保证每个输出 piece 使用：

```json
{
  "shapeId": 1,
  "rotation": 0,
  "arrowCell": { "x": 0, "y": 0 }
}
```

在 ArrowOut 的 Python 生成逻辑中，可以把随机形状选择限制为单格形状：

```python
shape_id = 1
```

同时仍然要保留不重叠检查、棋盘边界检查和方向可解性检查。单格关卡不依赖异形轮廓，难度应通过方块数量、填充率、方向阻挡顺序和颜色分组来控制。

## TapGallery 工具

`TapGallery/tap_db.py` 的核心类是 `ArrowPuzzleSolver`。它接收已有的二值网格或图片，把每个有内容的格子视为一个方块，然后使用模拟退火和依赖关系分析寻找较复杂、但仍然可解的方向分配。

它的输出主要是：

- 带箭头的结果图片。
- 描述方向和依赖关系的文本结果。

它不是 BlockOut ArtOut JSON 的直接生成器，也不会生成异形方块布局。若要将结果用于 BlockOut，需要增加一层转换，把每个网格格子映射为 `shapeId: 1` 的 piece，并转换方向名称、颜色和坐标字段。

运行示例：

```powershell
python Tools/LevelGenerators/TapGallery/tap_db.py `
  --mode batch --input input-images --output output-arrows --iterations 5000
```

该脚本依赖 `numpy` 和 `Pillow`。

## 生成结果接入 BlockOut 前的检查

无论使用哪套工具，写入 `Assets/Resources/ArtOut/Levels/` 前都应检查：

- `id` 唯一，并且在 `GameAssets.json` 中有对应条目。
- `width`、`height` 与所有方块占用格一致。
- 方块不越界、不重叠。
- `shapeId` 在 BlockOut 形状库范围内；单格关卡统一为 `1`。
- `arrowCell` 位于对应方块的局部占用格内。
- 方向使用 `Up`、`Down`、`Left`、`Right`。
- 通过 `Tools/LevelVerify` 或 `audit_levels.py` 检查后，再在 Unity 中由用户进行资源刷新和运行验证。

本说明只描述离线生成工具的用途和适配边界；本次不会自动执行生成，也不会触发 Unity 刷新、编译、运行或测试。
